# FF11-GearSwap-PLD (v6.7.2)

FF11(Windower 4)のナイト(PLD)用 GearSwap ジョブファイルです。ケアルの 3 段階着替えと、敵の魔法・TP技への自動着替えを入れています。

PLD.lua は、ナイト用の GearSwap のジョブファイルです。過去クロウラーの巣のマスターレベル上げ(マスポ)のように、大量の敵に殴られ続ける場所で、ケアルの詠唱が中断されないようにしつつ、着弾の直前だけ回復量の多い装備に着替えるために作りました。

敵の魔法や TP技の構えを見て、対魔法や状態異常耐性の装備に着替える機能もあります。

元にしているのは、「WindowerでFF11ライフ」(greeds.net)で公開されている GearSwap コードです。

v6.2 には、PLD.lua が読み込めなくなる不具合がありました。v6.2 を使っている方は、最新版に更新してください(詳しくは、末尾の更新履歴の v6.3)。

## ケアルの 3 段階着替え

すべての魔法で、次の順に着替えます。

1. 詠唱を始めた瞬間: `sets.precast.FC`
2. 詠唱中: `sets.midcast.interruption`(詠唱中断率を下げる装備。私の装備では、SIRD 100%)
3. 着弾の直前: ケアル系は `sets.midcast.Cure`、ほかの魔法は魔法ごとのセット

詠唱時間のほとんどを SIRD 100% の装備で守り、着弾の直前だけ、回復量や敵対心の装備に切り替えます。3 に切り替えるまでの時間は、詠唱時間 ×(1 − FC)− 調整秒数で計算します。FC は、`PLD_gear.lua` の `sets.precast.FC.value`(同梱の値は 69%)を使います。サポ赤なら、ジョブ特性の FC として 15% を足し、合計の上限は 80% です。

### 調整コマンド(`//gs c cureadjust`)

着弾の何秒前に 3 の装備へ切り替えるかを、`//gs c cureadjust <秒>` で決めます(初期値 0.30)。`//gs c cureadjust` だけで、今の設定を表示します。`//gs reload` をすると、0.30 に戻ります。

- ケアルの回復量が 0 になることがある(着弾装備が間に合っていない)ときは、増やします(例: `//gs c cureadjust 0.40`)。
- 詠唱の中断が増えた(SIRD 装備の時間が足りない)ときは、減らします(例: `//gs c cureadjust 0.20`)。ただし、減らすと、着弾装備が間に合わない回が出ます。
- 確かめるときは、HP が満タンの状態で、自分にケアルを唱えます。回復量が大きければ、間に合っています。0 なら、間に合っていません。

### 初期値を 0.08 秒から 0.30 秒にした理由(v6.7)

v6.6 までは、ケアルが完了する 0.08 秒前に、着弾装備へ着替えていました。ところが、着替えが間に合わず、回復量が 0 になることがありました。着替えの命令がサーバーに届くまでに、0.3〜0.4 秒ほどかかるためだと考えています(測定したのは、成功率だけです)。

HP が満タンの状態で、自分にケアルIV を唱え、調整秒数ごとに確かめました。着弾装備(HP の多い装備)が間に合うと、最大 HP が増えた分の約 1,070 を回復します。間に合わないと、0 です。

| 調整秒数 | 成功 | 備考 |
| --- | --- | --- |
| 0.08 秒(以前の初期値) | 2 / 6 | 実戦での記録 |
| 0.20 秒 | 7 / 10 | サポ赤 3/5、サポ青 4/5 |
| 0.30 秒(新しい初期値) | 10 / 10 | サポ赤 5/5、サポ青 5/5 |
| 0.40 秒 | 5 / 5 | サポ赤 |

0.08 秒の 2 / 6 は、実戦での記録で、ほかは、自分にケアルIV を唱えた試験です。回数が少ないので、参考程度の数字で、0.30 秒は、0.20 秒より成功が多く、0.40 秒と同じくらいだったので、安全側の値として選びました。早めた分だけ、SIRD 装備を着ている時間は短くなります。サポ赤(FC が上限の 80%)だと、ケアルIV の詠唱は約 0.5 秒なので、SIRD 装備は 0.2〜0.3 秒ほどです。通信の状況で変わるので、合わないときは `//gs c cureadjust` で調整してください。

## 敵の魔法への自動迎撃

敵が自分に魔法を詠唱し始めたとき、または範囲魔法(名前がガ・ジャで終わる魔法、メテオなど)を詠唱し始めたときに、アクションパケットで検知して着替えます。

- 状態異常の魔法(スリプル、サイレス、パライズ、ブレイクなど): `sets.StatusResist`
- それ以外: `sets.idle.Magical`
- 敵の魔法が着弾したら、待機・戦闘の装備に戻ります。詠唱が中断されたときも戻ります。
- 着弾も中断も確認できないときは、その魔法の詠唱時間 ×2 + 2 秒で戻ります。詠唱していた敵が倒れていた場合は、次の着替えの判定のときに戻ります。
- フェイスの詠唱では着替えません。ほかの人のペットの詠唱も、除外する作りですが、ゲーム内では確かめていません。
- 自分の詠唱中に敵の魔法が着弾したときは、着替えません。
- `//gs debugmode` をオンにすると、迎撃のきっかけになった魔法の名前を、チャットに出します。

自分が魔法を詠唱している間は、自分の着替え(FC、SIRD、着弾装備)を優先し、迎撃と被ファランクスの着替えはしません。たとえば、ケアルIV の詠唱中に、敵がブリザドIV を詠唱し始めても、ケアルIV の着替えを崩しません。自分の魔法が終わった時点で、敵の魔法(またはファランクス)がまだ着弾していなければ、そこで着替えます。重なったときは、状態異常耐性、対魔法、被ファランクスの順に優先します。

クエイクやフリーズのように、着弾まで 14 秒ほどかかる魔法で、着弾の前に装備が戻る問題があったため(v6.4)、期限を「詠唱時間 ×2 + 2 秒」にしています。これは、ゲーム内でクエイクを 2 回受けて、どちらも着弾まで装備が続くことを確かめました。範囲魔法の見分け(ゲイン系やマドリガルなど 29 種類の魔法には反応せず、ガ系・ジャ系・メテオなど 74 種類には反応する)は、魔法の一覧と突き合わせて数えました。

## 敵の TP技への自動着替え(v6.5 から)

敵の TP技(特殊技)の構えも検知して、着替えます。

- 魔法属性・ブレスのダメージ技: `sets.idle.Magical`
- 状態異常だけの技、視線の技: `sets.StatusResist`
- 物理の技と、分類表に載っていない技: 着替えません(普段の装備で受けます)
- 自分が対象の技か、範囲技のときだけ着替えます。技が発動するか、構えが中断されたら、戻ります。発動のパケットが届かないときのために、構えから 6 秒たつと、戻ります。

技の分類は、`mob_tp_moves.lua`(魔法属性 879 技、状態異常 453 技、範囲 1457 技)を使います。このファイルを置かなければ、TP技では着替えません(魔法の迎撃は、今までどおり動きます)。`//gs debugmode` をオンにすると、敵が構えた技の番号・名前・分類が、チャットに出ます。分類表にない技を見つけるのに使えます。

分類は、LandSandBoat(FF11 のエミュレータ)の技データと、BG-wiki・FF11用語辞典の記述から作っています。エミュレータの実装が元なので、本家と違う技があるかもしれません。ドメインベイジョンの Quetzalcoatl(セイブルブレス、サイクロンウィング)で、構えで着替えて、発動で戻ることを確かめています。

v6.6 で、獣人やシャドウ族のような人型の敵が使うウェポンスキルの番号(1〜255)を、分類表に足しました。レッドロータス・セラフブレードのような、属性のウェポンスキルの構えで、`sets.idle.Magical` に着替えます。足した数は、魔法属性 48、状態異常だけの技 7、範囲 23 です。この追加分は、ゲーム内でまだ試していません。

### 迎撃を止める(`kurosu` モード / `MagicalCut`)

物理で殴ってくる敵が多い場所では、敵の魔法や TP技に合わせて対魔法装備へ替えると、かえって被ダメージが増えます。そこで、迎撃の着替えを止められるようにしました。

| 方法 | 内容 |
| --- | --- |
| 待機モードか戦闘モードを `kurosu` にする | そのあいだ、対魔法装備(`sets.idle.Magical`)と状態異常耐性装備(`sets.StatusResist`)に着替えません |
| `//gs c toggle MagicalCut` | モードに関係なく、同じ着替えをオン・オフします(初期値オン。`//gs reload` でオンに戻ります) |

どちらの場合も、被ファランクスの着替えは、今までどおり行います。迎撃装備を着ている最中に止めると、すぐ普段の装備に戻ります。切り替えたときは、チャットに「敵の魔法・TP技に合わせた着替え(対魔法・状態異常耐性)」で始まるメッセージが出ます。

## 被ファランクスの自動着替え

フェイスやパーティーメンバーが、自分にファランクスまたはファランクスIIを詠唱し始めたら、`sets.midcast.IncreasedPhalanx` に定義した装備へ着替えます。着弾したら、待機・戦闘の装備に戻ります。詠唱が中断されたときも戻ります。着弾も中断も確認できないときは、詠唱時間 ×2 + 2 秒(ファランクスなら 8 秒)で戻ります。`state.Increased` が ON(初期値)のときに動きます。ON のときは、ファランクス以外の強化(プロテス、シェル、リジェネ、カーズナ)でも、greeds.net 版と同じように、3 秒固定で着替えます。

同じパーティーの学者が「女神降臨の章」のあとに唱える範囲ファランクスでも、同じように着替えます(v6.6)。この場合、ファランクスの対象は学者自身のままです。そのため、同じパーティーの人が「女神降臨の章」を使ったことを覚えておき、その人がファランクスを唱え始めたら着替えて、着弾した瞬間に戻します。学者が離れていて範囲の外にいるときも、着替える場合があります。フェイスなどが、自分自身にだけ掛けるファランクスでは、これまでどおり着替えません。私の環境では、詠唱開始と同時に着替え、着弾から 0.1 秒以内に戻ることを、6 回確認しました(過去クロウラーの巣、学者と同じパーティー)。

`user-globals.lua` の「着替えてから 3 秒固定で戻す」処理は、ナイトのファランクスに限って働かないようにしました(`PLD.lua` が、装備セットを `sets.ReceivedPhalanx` という名前に移します)。`PLD_gear.lua` の書き方は、今までと同じで、`sets.midcast.IncreasedPhalanx` に定義してください。この「名前を移す」作りは、フェイスのファランクスII を 8 回受けて、8 回とも、詠唱開始と同時に着替え、着弾から 0.1 秒以内に戻ることを確かめました。

## 最高敵対心のセット(`sets.EnmityMax`)

`PLD_gear.lua` に、敵対心だけを優先した `sets.EnmityMax` があります。`sets.Enmity` から、胴・左耳・右指を、敵対心の高い装備に替えたもので、私の装備では、敵対心が 15 増えます。使うのは、パリセード・センチネル・リアクト・ランパート・マジェスティ・フォイル・ヴァレションの 7 つです。どれも、着ているのは一瞬(リアクトとフォイルは詠唱のあいだ)なので、HP と被ダメージカットが下がることを受け入れています。センチネルの足(ＣＢレギンス+3)と、ランパートの頭(ＣＢコロネット+3)は、アビリティを強化する装備なので、残しています。ほかのアビリティやフラッシュなどは、今までどおり `sets.Enmity` です。`sets.EnmityMax` は、同梱の `PLD_gear.lua` で追加したので、自分の `PLD_gear.lua` を使い続けるときは、該当の部分を写してください。

## 武器も替わります

同梱の `PLD_gear.lua` では、`sets.idle.Magical`(マリグナスソードとイージス)と、被ファランクスの装備(サクパタソードとプリュウェン)に、武器が入っています。そのため、迎撃と被ファランクスのときに、武器も持ち替えます。メイン武器を替えると、TP は 0 になります。武器を替えたくないときは、これらのセットから `main` と `sub` を外してください。

## 導入と更新

1. greeds.net の GearSwap コード一式(`user-globals.lua` など)を入れておきます。導入方法は、[配布ページ](https://greeds.net/gearswap-code-list/)を確認してください。
2. このリポジトリの Code → Download ZIP で、ファイル一式をダウンロードして解凍します。
3. ファイルを置きます。同じ名前のファイルは上書きになるので、元のファイルを退避しておくと安心です。

```text
GearSwap/
  data/
    PLD.lua                 ← このリポジトリの PLD.lua
    user-globals.lua        ← greeds.net 版のまま
    キャラクター名/
      PLD_gear.lua          ← このリポジトリの PLD_gear.lua
    mob_tp_moves.lua        ← このリポジトリの mob_tp_moves.lua(TP技の迎撃を使う場合)
```

4. `PLD_gear.lua` の装備を自分の持ち物に書き換え、`sets.precast.FC.value` を、自分の FC 装備の値(%)に直します。
5. ゲーム内で `//gs reload` を実行します。`//gs showswaps` を ON にすると、着替えをチャットで確認できます。
6. マスポなど回線が重い環境では、`//gs c cureadjust 0.40` などで、着替えのタイミングを調整してください。

以前の版から更新するときは、`PLD.lua` を上書きし、TP技の迎撃を使うなら、`mob_tp_moves.lua` を `GearSwap/data/` に置いてください。自分で編集した `PLD_gear.lua` は、そのまま使えますが、`sets.EnmityMax` を使うなら、同梱の `PLD_gear.lua` の該当部分を写してください。

動作環境は、Windower 4(日本語クライアント)と、GearSwap(Mote-Include)で、ナイトで使います。前提として、greeds.net 版の `user-globals.lua` が必要です。不具合や要望は、GitHub の Issues で教えてください。
