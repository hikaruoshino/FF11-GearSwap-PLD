# 【FFXI GearSwap】ナイト (PLD) SIRD100%ケアル着替え ＆ 敵魔法・TP技自動迎撃スクリプト (v6.7.1)

FF11（ファイナルファンタジーXI）のナイト（PLD）用 GearSwap スクリプトです。
**[WindowerでFF11ライフ（greeds.net）](https://greeds.net/gearswap-code-list/)** の GearSwap コードを元に、過去クロウラーの巣のマスターレベル上げ（マスポ）のような、大量の敵に殴られ続ける環境向けに手を入れています。

* 魔法は **FC → SIRD 100%（詠唱中断を防ぐ装備）→ 着弾の直前だけ効果装備** の3段階で着替えます。
* 着弾の何秒前に着替えるかを、ゲーム内のコマンドで調整できます。
* 敵が自分や範囲に魔法を詠唱し始めたら、状態異常耐性や魔法防御の装備に自動で着替えます。
* 敵の TP技（特殊技）の構えにも、技の種類に合わせて着替えます（v6.5）。
* 物理で殴られ続ける場所では、迎撃の着替えを止められます（v6.5）。
* 学者の範囲ファランクスを受けたときも、着弾した瞬間に元の装備へ戻ります（v6.6）。
* パリセードなど 5 つの行動は、敵対心を最優先にしたセットで使います（v6.6）。

## 🌟 v6.7 の変更

### ケアル装備への着替えを早めた（初期値 0.08 秒 → 0.30 秒）
v6.6 までは、ケアルが完了する 0.08 秒前に着弾装備へ着替えていました。ところが実際には、**着替えが間に合わず、ケアルの回復量が 0 になる**ことがありました。着替えの命令がサーバーに届くまでに、0.3〜0.4 秒ほどかかるためです。

HP が満タンの状態で自分にケアルIV を唱えて、調整秒数ごとに確かめました。着弾装備（HP の多い装備）が間に合うと、最大 HP が増えた分の約 1,070 を回復します。間に合わないと 0 です。

| 調整秒数 | 成功 | 備考 |
| :--- | :--- | :--- |
| 0.08 秒（これまでの初期値） | 2 / 6 | 実戦での記録 |
| 0.20 秒 | 7 / 10 | サポ赤 3/5、サポ青 4/5 |
| **0.30 秒（新しい初期値）** | **10 / 10** | サポ赤 5/5、サポ青 5/5 |
| 0.40 秒 | 5 / 5 | サポ赤 |

* 着替えの命令から結果が届くまでが 0.5 秒以上あった回は、すべて成功していました。
* 早めた分だけ、SIRD 装備を着ている時間は短くなります。サポ赤（FC が上限の 80%）だとケアルIV の詠唱は約 0.5 秒なので、SIRD 装備は 0.2〜0.3 秒ほどです。
* 通信の状況で変わるので、合わないときは `//gs c cureadjust <秒>` で調整してください。

## 🌟 v6.6 の新機能

### 学者の範囲ファランクスも、着弾で戻す
学者が「女神降臨の章」のあとに唱えるファランクスは、対象が学者自身のまま範囲になります。v6.5 までは「**自分に**向けたファランクス」だけを見ていたので、この範囲ファランクスでは着弾を検知できず、`user-globals.lua` 側の処理（着替えてから 3 秒固定で戻す）に任せる形になっていました。

v6.6 では、次のように動きます。

1. 同じパーティーの人が「女神降臨の章」を使ったことを覚えておきます。
2. その人がファランクスを唱え始めたら、被ファランクス装備に着替えます。
3. **着弾した瞬間に**、待機・戦闘の装備に戻します。

* 作者の環境では、詠唱開始と同時に着替え、着弾から 0.1 秒以内に戻ることを 6 回確認しました（過去クロウラーの巣、学者と同じパーティー）。
* フェイスなどが自分自身にだけ掛けるファランクスでは、今までどおり着替えません。
* `user-globals.lua` の「3 秒固定で戻す」処理は、ナイトのファランクスに限って働かないようにしました（`PLD.lua` が装備セットを `sets.ReceivedPhalanx` という名前に移します）。`PLD_gear.lua` の書き方は今までと同じで、`sets.midcast.IncreasedPhalanx` に定義してください。この「名前を移す」作りは、作者の環境で（フェイスのファランクスII を 8 回受けて）8 回とも、詠唱開始と同時に被ファランクス装備へ着替え、着弾から 0.1 秒以内に戻ることを確認しました。

### 最高敵対心のセット（sets.EnmityMax）
`PLD_gear.lua` に、敵対心だけを優先した `sets.EnmityMax` を足しました。`sets.Enmity` から胴・左耳・右指を敵対心の高い装備に替えたもので、作者の装備では敵対心が 15 増えます。

* 使うのは **パリセード・センチネル・リアクト・ランパート・マジェスティ** の 5 つです。どれも着ているのは一瞬（リアクトは詠唱の間）なので、HP と被ダメージカットが下がることを受け入れています。
* センチネルの足（ＣＢレギンス+3）と、ランパートの頭（ＣＢコロネット+3）は、アビリティを強化する装備なので残しています。
* ほかのアビリティ・フラッシュなどは、今までどおり `sets.Enmity` です。

### 人型の敵のウェポンスキルにも着替える
獣人やシャドウ族のような人型の敵は、プレイヤーと同じウェポンスキルを使います。分類表 `mob_tp_moves.lua` に、これらの番号（1〜255）を足しました。レッドロータス・セラフブレードのような属性のウェポンスキルの構えで、`sets.idle.Magical` に着替えます。

* 足した数は、魔法属性 48・状態異常だけの技 7・範囲 23 です。
* この追加分は**ゲーム内ではまだ試していません**。

## 🌟 v6.5 の新機能

### 敵の TP技にも自動で着替える
これまでの迎撃は敵の**魔法**だけが対象でした。v6.5 では、敵の **TP技（特殊技）の構え**も検知して着替えます。

* 魔法属性・ブレスのダメージ技: `sets.idle.Magical`
* 状態異常だけの技・視線の技: `sets.StatusResist`
* 物理の技と、分類表に載っていない技: 着替えません（普段の装備で受けます）
* 自分が対象の技か、範囲技のときだけ着替えます。技が発動するか、構えが中断されたら戻ります。

技の分類は、同梱の **`mob_tp_moves.lua`**（魔法属性 879 技・状態異常 453 技・範囲 1457 技）を使います。このファイルを置かなければ、TP技では着替えません（魔法の迎撃は今までどおり動きます）。

`//gs debugmode` をオンにすると、敵が構えた技の番号・名前・分類がチャットログに出ます。分類表に無い技を見つけるのに使えます。

> 分類は LandSandBoat（FF11 エミュレータ）の技データと、BG-wiki・FF11用語辞典の記述から作っています。エミュレータの実装が元なので、本家と違う技があるかもしれません。ドメインベージョンの Quetzalcoatl（セイブルブレス、サイクロンウィング）では、構えで着替えて発動で戻ることを確かめています。

### 迎撃の着替えを止める（kurosu モード / MagicalCut）
物理で殴ってくる敵が多い場所では、敵の魔法や TP技に合わせて対魔法装備へ替えると、かえって被ダメージが増えます。そこで、迎撃の着替えを止められるようにしました。

| 方法 | 内容 |
| :--- | :--- |
| 待機モードか戦闘モードを `kurosu` にする | そのあいだ、対魔法装備（`sets.idle.Magical`）と状態異常耐性装備（`sets.StatusResist`）に着替えません |
| `//gs c toggle MagicalCut` | モードに関係なく、同じ着替えをオン・オフします（初期値オン。`//gs reload` でオンに戻ります） |

* どちらの場合も、**被ファランクスの着替えは今までどおり行います**。
* 迎撃装備を着ている最中に止めると、すぐ普段の装備に戻ります。
* 切り替えたときは、チャットに「敵の魔法・TP技に合わせた着替え: する / しない」と出ます。

## 🌟 主な機能

### 1. 魔法の3段階着替え（FC → SIRD 100% → 着弾装備）
すべての魔法で、次の順に着替えます。

1. **詠唱開始の瞬間**: `sets.precast.FC`
2. **詠唱中**: `sets.midcast.interruption`（詠唱中断率 100% ダウン）
3. **着弾の直前**: 魔法ごとの装備。ケアル系はすべて `sets.midcast.Cure`、それ以外は `sets.midcast['魔法名']` など

3 に切り替えるまでの時間は、**詠唱時間 ×（1 − FC）− 調整秒数** で計算します。

* FC は `PLD_gear.lua` の `sets.precast.FC.value`（同梱の値は 69%）を使います。
* サポ赤なら、ジョブ特性の FC として 15% を足します。合計の上限は 80% です。

### 2. 着替えタイマーの調整コマンド
| コマンド | 内容 |
| :--- | :--- |
| `//gs c cureadjust <秒>` | 着弾の何秒前に 3 の装備へ切り替えるか（初期値 0.30） |
| `//gs c cureadjust` | 今の設定を表示 |

* **ケアルの回復量が 0 になることがある**（着弾装備が間に合っていない）: 増やします。例: `//gs c cureadjust 0.40`
* **詠唱の中断が増えた**（SIRD 装備の時間が足りない）: 減らします。例: `//gs c cureadjust 0.20`。ただし、減らすと着弾装備が間に合わない回が出ます。
* 確かめ方: HP が満タンのときに自分へケアルを唱えます。回復量が大きければ間に合っていて、0 なら間に合っていません。

`//gs reload` をすると 0.30 に戻ります。

### 3. 敵魔法の自動迎撃
敵が**自分に**魔法を詠唱し始めたとき、または**範囲魔法**（名前がガ・ジャで終わる魔法、メテオなど）を詠唱し始めたときに、アクションパケットで検知して着替えます。

* 状態異常の魔法（スリプル、サイレス、パライズ、ブレイクなど）: `sets.StatusResist`
* それ以外: `sets.idle.Magical`
* **敵の魔法が着弾したら**、待機・戦闘の装備に戻ります。詠唱が中断されたときも戻ります。
* 着弾も中断も確認できないときは、その魔法の詠唱時間×2＋2秒で戻ります。詠唱していた敵が倒れたときも戻ります。
* `//gs debugmode` をオンにすると、迎撃のきっかけになった魔法の名前がチャットログに出ます。
* フェイスや他の人のペットの詠唱では着替えません。
* `kurosu` モードのとき、または `//gs c toggle MagicalCut` でオフにしているときは着替えません（「v6.5 の新機能」を参照）。

**敵の TP技（v6.5）** も、構えを検知して同じように着替えます。魔法属性・ブレスの技は `sets.idle.Magical`、状態異常だけの技は `sets.StatusResist`、物理の技と分類表に無い技は着替えません。分類は `mob_tp_moves.lua` を使います。

### 4. 被ファランクスの自動受け取り
フェイスやパーティーメンバーが**自分に**ファランクス／ファランクスIIを詠唱し始めたら、`sets.midcast.IncreasedPhalanx` に定義した装備へ着替えます。同じパーティーの学者が「女神降臨の章」のあとに唱える**範囲ファランクス**でも同じです（v6.6）。

* **着弾したら**、待機・戦闘の装備に戻ります。詠唱が中断されたときも戻ります。
* 着弾も中断も確認できないときは、詠唱時間＋2秒（5秒）で戻ります。
* `state.Increased` が ON（初期値）のときに動きます。

### 5. 自分の詠唱を優先
自分が魔法を詠唱している間は、**自分の着替え（FC → SIRD → 着弾装備）を優先**し、迎撃と被ファランクスの着替えはしません。たとえばケアルIVの詠唱中に敵がブリザドIVを詠唱し始めても、ケアルIVの着替えを崩しません。

* 自分の魔法が終わった時点で、敵の魔法（またはファランクス）が**まだ着弾していなければ**、そこで迎撃・被ファランクスの装備に着替えます。
* 自分の詠唱中に敵の魔法が着弾したときは、着替えません。
* 重なったときは、状態異常耐性 ＞ 対魔法 ＞ 被ファランクスの順に優先します。

> ⚠️ **武器も替わります**: 同梱の `PLD_gear.lua` では、`sets.idle.Magical`（マリグナスソード＋イージス）と被ファランクスの装備（サクパタソード＋プリュウェン）に武器が入っているため、迎撃と被ファランクスのときに武器も持ち替えます。メイン武器を替えると TP は 0 になります。武器を替えたくない場合は、これらのセットから `main` と `sub` を外してください。

| 被ファランクス | 手動（`state.Increased` は初期値 OFF） | 自分へのファランクスと、学者の範囲ファランクスの詠唱開始で着替え、着弾で戻す（初期値 ON） |
| 敵対心装備 | `sets.Enmity` | パリセードなど 5 つは `sets.EnmityMax`（敵対心を最優先） |
| モード | 待機 Normal / 戦闘 Normal・SubtleBlow | 待機 Normal・kurosu / 戦闘 Normal・kurosu・Magical |
| 武器の候補 | ブルトガング、マレヴォレンス | マリグナスソードを追加 |
| キーの割り当て | Shift+F7 でサブ武器の切り替え | 割り当てなし |
| 装備定義の読み込み | 通常どおり | `PLD_gear.lua` が無ければ `キャラクター名_gear.lua` も探す |

## 📂 インストール

1. greeds.net の GearSwap コード一式（`user-globals.lua` など）を入れておきます。導入方法は [配布ページ](https://greeds.net/gearswap-code-list/) を確認してください。
2. このリポジトリを **Code → Download ZIP** でダウンロードし、解凍します。
3. ファイルを置きます（同じ名前のファイルは上書き。上書きの前に元のファイルを退避しておくと安心です）。
   ```
   GearSwap/
     data/
       PLD.lua                 ← このリポジトリの PLD.lua
       user-globals.lua        ← greeds.net 版のまま
       キャラクター名/
         PLD_gear.lua          ← このリポジトリの PLD_gear.lua
       mob_tp_moves.lua        ← このリポジトリの mob_tp_moves.lua（TP技の迎撃を使う場合）
   ```
4. `PLD_gear.lua` の装備を自分の持ち物に書き換え、`sets.precast.FC.value` を自分の FC 装備の値（%）に直します。
5. ゲーム内で `//gs reload` を実行します。`//gs showswaps` を ON にすると、着替えをチャットで確認できます。
6. マスポなど回線が重い環境では、`//gs c cureadjust 0.40` などで着替えのタイミングを調整してください。
